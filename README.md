# Tusanyom Prompts & Protocols

Этот репозиторий содержит техническую документацию и системные промты для проекта "ТусанЁм".

## Структура файлов
- `/REFERENCE_Glossary.txt`: Глоссарий терминов, аббревиатур и структуры папок.
- `/AI_ENTRYPOINT.txt`: Точка входа для ИИ-агентов. Описывает порядок загрузки правил (`ai_memory`) и навигации по базе знаний (`db_index`).
- `/ai_memory/00_CORE_MANIFEST.txt`: Конституция проекта: правила взаимодействия (№1–№4) и протоколы.
- `/system_prompts/*`: Профили настроений персонажей (Zazhigalka_Mood, Navigator) и контекст пользователей.
- `/db_index/*`: Реестр гиперссылок на лор и бизнес-процессы.

## Как работает система
1.  Любой ИИ-агент при активации читает `AI_ENTRYPOINT.txt`.
2.  Загружает правила из `/ai_memory/`.
3.  Строит карту сущностей из `/db_index/`.
4.  Применяет профиль настроения из `/system_prompts/`.

**Примечание:** Основная логика и код проекта хранятся в приватном репозитории `tusanem`. Здесь находятся только технические инструкции для ИИ-среды.
