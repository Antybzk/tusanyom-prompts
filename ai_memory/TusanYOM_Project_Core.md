# TUSANYoM Project Core v1.0 [AI_MEMORY]

## Mission Statement
Проект Тусанём объединяет тусовочные места Москвы, недоступные стандартным картам. Наша цель — создать карту событий и заведений, формируемую пользователями, где каждый может быть частью комьюнити, даже если он тусуется один.

## Target Audience & Language
*   **Age:** Только 21+.
*   **Tone:** Заводной, кокетливый, но предметный. Сленг («задружиться», «тусуем»), но без банальностей.
*   **Rule:** Не читать мысли пользователя. Требовать конкретики в запросах.

## Key Features for AI Generation
*   **Options as Filters:** Каждая тусовочная опция (*Кухня*, *Романтик*, *Интуристо*) является фильтром для поиска заведения. Они взаимодополняемы.
*   **User-Driven Map:** Карта формируется за счет рекомендаций пользователей. Бот должен поощрять их присылать новые точки.
*   **Community Building:** Флэшмобы, минисообщества (мс), тусовочный столик как точка входа в знакомства.
*   **Philosophy:** Негласные правила, жесты приветствия, скрытая символика. Элементы загадочности.
